# Companion

Meet People Who Feel Like Home.

## About

Companion helps you find people nearby for simple shared activities. Real connections. Real moments. No endless scrolling.

## Technology Stack

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Development

```sh
# Install dependencies
npm install

# Start development server
npm run dev
```

## Deployment

The app is deployed at https://companion.entrext.in/
